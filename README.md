# sshtp

**给 SSH 隧道一个面板。**

散落的 `ssh -L` 是隐形的 —— 不知道哪条还活着、跑了多久、搬了多少数据、有没有重复起。sshtp 把本机所有 SSH 隧道收进一张状态表，并在同一屏里起停它们。

## 核心

- **面板** —— 一屏看完：编号 / 方向 / 本地ip:端口 / 转发目标 / SSH主机 / 持续时间 / 通讯量 / 来源 / PID / 说明。**含其他程序起的、`~/.ssh/config` 里的**，不只本程序起的
- **后台** —— 隧道后台运行，**不占终端窗口**，关掉终端也不断
- **TUI / CLI 二合一** —— 同一套键位、同一个 core。人按键用 TUI，agent 带参数调 CLI，**不用学两套**
- **参数化** —— 一个子命令一个动作、参数直接给；CLI 全程无交互、退出码语义化，可直接被脚本和 agent 调用

## 用法

```
sshtp                                                        # 面板一屏 + 键位表；5 秒内按任意键进 TUI，否则退出
sshtp v                                                      # 查看配置
sshtp n [L|R] <说明> <本地ip:端口> <远程ip:端口> <user@host>    # 新建（方向省略即 L）
sshtp e <编号> <字段> <新值>                                    # 修改
sshtp x <编号>                                                 # 删除配置
sshtp c <编号>                                                 # 连接
sshtp d <编号>                                                 # 断开
```

同一个键，在 TUI 里是「按键 → 执行」，在 CLI 里是「一次性执行 → 退出」。

注意两套编号：`v` / `e` / `x` / `c` 用**配置行号**，`d` 用**状态表序号**（会随扫描结果漂移）。

## 文件

程序与本程序生成的文件同目录、扁平放置：

| 文件 | 说明 |
|---|---|
| `.tunnel.conf` | 隧道列表，5 列逗号分隔：`方向,说明,本地,远程,登录`。程序「新建」时生成，**不入库** |
| `.sshtp.pid` | 在跑隧道的 pid 记录；**不入库** |
| `.sshtp.log` | 日志，一行六段，只增不删；**不入库** |

配置文件名 `.tunnel.conf`（五列，含方向列）取代了旧的 `sshtp.cfg`（四列）。

## 构建

Go 版源码在 `go/`。产物名固定（规则见 [`需求文档.0.02.md`](需求文档.0.02.md) §1），构建时**必须显式指定产物名**，产物落在**项目根目录**：

```sh
cd go
go build -o ../sshtp        # mac / Linux
go build -o ../sshtp.exe    # Windows
```

Go 按**目录名**给产物命名——不加 `-o` 会得到一个名叫 `go` 的文件。

## 依赖

`bash` / `ps` / `lsof` / `ssh`，macOS 与 Linux 自带，无需安装。

「通讯量」列另行取数：macOS 用 `nettop`，Linux 用 `ss`；取不到时该列记 `-`，不影响其余功能。

Windows：shell 版不可行（`ps` 看不到原生 Windows 进程，且没有 `lsof`）。
