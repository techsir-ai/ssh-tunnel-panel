# sshtp

SSH 本地转发隧道管理器（macOS / Linux）。把配置里的一行拼成一条最简 `ssh -N -L` 命令，并统一管理这些隧道的起停与状态。

## 用法

```
sshtp            # 状态 + 键位表；3 秒内按任意键进菜单，否则退出
sshtp v          # 查看配置
sshtp n <说明> <本地ip:端口> <远程ip:端口> <user@host>   # 新建
sshtp e <编号> <字段> <新值>                             # 修改
sshtp x <编号>                                           # 删除配置
sshtp c <编号>                                           # 连接
sshtp d <编号>                                           # 断开
```

CLI 与 TUI 共用同一套键位：一个键 = 一个子命令。TUI 里按键是「交互 → 执行」，CLI 里是「一次性执行 → 退出」。裸跑 `sshtp` 一次即可拿到全部功能与参数形状。

## 特点

- 扫描**本机所有**隧道（含其他程序起的、`~/.ssh/config` 里的），不限于本程序起的
- 只依赖 `bash` / `ps` / `lsof` / `ssh`，不引入任何外部库
- CLI 全程不可交互、退出码语义化，便于被 agent 直接调用

## 文件

| 文件 | 说明 |
|---|---|
| `sshtp` | 程序本体（bash，无扩展名） |
| `sshtp.cfg` | 配置，四列逗号分隔；**由程序「新建」时生成，不入库** |
| `需求文档.md` | 完整需求、界面约定与技术要点 |

## 依赖

`bash` / `ps` / `lsof` / `ssh`。macOS 与 Linux 自带，无需安装。

macOS 下额外用 `nettop` 显示「通讯量」列；Linux 无此列，显示 `-`，其余功能不受影响。

Windows / Git Bash 不可行：`ps` 看不到原生 Windows 进程，且没有 `lsof`。
