# sshtp

**给 SSH 隧道一个面板。**

散落的 `ssh -L` 是隐形的——不知道哪条还活着、跑了多久、搬了多少数据、有没有重复起。sshtp 把本机所有隧道收进一张状态表，并在同一屏里起停它们。

**状态**：0.02 需求已定，两种实现——**bash 版已可用**（本仓库现成程序），**Go 版待实现**（TUI / CLI / HTTP 三合一，并支持 Windows）。

## 核心

- **面板** —— 9 列一屏看完：编号 / 监听地址 / 转发目标 / SSH 主机 / 持续时间 / 通讯量 / 来源 / PID / 说明。**含其他程序起的、`~/.ssh/config` 里的**，不只本程序起的
- **后台** —— 隧道后台运行，**不占终端窗口**，关掉终端也不断
- **TUI / CLI 二合一** —— 同一套键位、同一个 core。人按键用 TUI，agent 带参数调 CLI，**不用学两套**
- **参数化** —— 一个子命令一个动作、参数直接给；CLI 全程无交互、退出码语义化，可直接被脚本和 agent 调用

## 用法

```
sshtp            # 面板一屏 + 键位表；3 秒内按任意键进 TUI，否则退出
sshtp v          # 查看配置
sshtp n <说明> <本地ip:端口> <远程ip:端口> <user@host>   # 新建
sshtp e <编号> <字段> <新值>                             # 修改
sshtp x <编号>                                           # 删除配置
sshtp c <编号>                                           # 连接
sshtp d <编号>                                           # 断开
```

同一个键，在 TUI 里是「按键 → 执行」，在 CLI 里是「一次性执行 → 退出」。

## 依赖

bash 版：`bash` / `ps` / `lsof` / `ssh`，macOS 与 Linux 自带，无需安装。macOS 下额外用 `nettop` 显示「通讯量」列；Linux 无此列，显示 `-`，其余功能不受影响。

Windows：**bash 版不可行**（`ps` 看不到原生 Windows 进程，且没有 `lsof`）；0.02 的 **Go 版**将支持 Windows。
